
Este proyecto consiste en la creación del clásico juego de **Piedra, Papel o Tijeras** desarrollado en Python para dos jugadores. El programa solicita los nombres de los participantes y permite que ambos ingresen su elección hasta que exista un ganador.

El juego incluye validaciones para manejar diferencias entre mayúsculas y minúsculas en las respuestas, compara las elecciones de los jugadores y determina si existe un ganador o si deben repetir la partida debido a un empate.
